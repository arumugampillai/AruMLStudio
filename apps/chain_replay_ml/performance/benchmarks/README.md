# Benchmark reports

Generated by:

```bash
cd angelone/chart
python -m chain_replay_ml.performance.benchmark --rows 100000
```

Release gate (rows/sec must stay within 20% of `baseline.json`):

```bash
python -m chain_replay_ml.performance.benchmark --check-regression
# or against an existing report without re-running:
python -m chain_replay_ml.performance.benchmark --regression-only
```

Dashboard:

```bash
python -m chain_replay_ml.performance.dashboard
```

See `docs/project-main/feature-engine/PERFORMANCE.md`.
