## 1. Purpose & Scope

Phase 1 established a configurable, multi-context, versioned policy engine with immutable evidence logging and safe dual summary projections.

**Phase 2A** adds **Evidence Intelligence** as a query-time derived analytical layer:
1. **Evidence Confidence**: Mitigates small-sample distortions by quantifying observation volume saturation.
2. **Recency / Staleness**: Quantifies elapsed time since the latest validation run into descriptive freshness bands.
3. **Corrected Model Consensus (with Strict Tie Handling)**: Resolves multi-vote counting defects and distinguishes true dominant consensus from 50/50 splits.
4. **Base Operational Rank (Dual-Column Advisory Signal)**: Preserves Phase 1 raw rank while introducing a confidence-dampened operational priority score as an advisory preview.

---

## 2. Core Architectural Invariants `[VERIFIED]`

1. **Evidence DB Immutability**: `recommendation_evidence` records historical ground truth. Phase 2A calculations never issue `UPDATE` or `DELETE` on raw evidence.
2. **Phase 1 Lifecycle Governance Authority**:
   - **Experimental Blocking Gate**: Strictly governed by `consecutive_remove_count >= remove_block_consecutive_threshold` or `remove_runs >= remove_block_total_threshold`.
   - **Experimental Promotion Candidate**: Strictly governed by `consecutive_keep_count >= promotion_candidate_consecutive_keep`, `score >= promotion_candidate_min_score`, and `unique_models_count >= experimental_promotion_min_unique_models`.
   - **Population Immunities**: Base Pipeline and Feature Registry features remain strictly immune from automatic blocking or code-level deletion.
3. **Context-Keyed Isolation**: All Phase 2A metrics are calculated independently per `context_id` (Market $\times$ Interval $\times$ Sliding Window $\times$ Project ID). No cross-context mixing occurs.

## 3. Mathematical Specifications `[IMPLEMENTED & VERIFIED]`

### 3.1. Evidence Confidence ($C$)
Implemented in [`apps/chain_replay_ml/production_validation/recommendation_policy.py`](file:///c:/Users/admin/PycharmProjects/AruMLStudio/apps/chain_replay_ml/production_validation/recommendation_policy.py#L515-L540):

$$C = \sqrt{C_{\text{runs}} \times C_{\text{models}}}$$

Where:
$$C_{\text{runs}} = 1 - \exp\left(-\frac{N_{\text{runs}}}{k_{\text{runs}}}\right) \quad (k_{\text{runs}} = 3.0)$$
$$C_{\text{models}} = 1 - \exp\left(-\frac{M_{\text{unique}}}{k_{\text{models}}}\right) \quad (k_{\text{models}} = 2.0)$$

#### Exact Reference Values Asserted in Tests:
- $N=0, M=0 \implies C = 0.000$ ($0.0\%$)
- $N=1, M=1 \implies C = \sqrt{0.2835 \times 0.3935} \approx \mathbf{0.3340}$ ($33.4\%$)
- $N=2, M=2 \implies C = \sqrt{0.4866 \times 0.6321} \approx \mathbf{0.5546}$ ($55.5\%$)
- $N=3, M=2 \implies C = \sqrt{0.6321 \times 0.6321} = \mathbf{0.6321}$ ($63.2\%$)
- $N=3, M=3 \implies C = \sqrt{0.6321 \times 0.7769} \approx \mathbf{0.7008}$ ($70.1\%$)
- $N=5, M=3 \implies C = \sqrt{0.8111 \times 0.7769} \approx \mathbf{0.7938}$ ($79.4\%$)
- $N=10, M=4 \implies C = \sqrt{0.9643 \times 0.8647} \approx \mathbf{0.9131}$ ($91.3\%$)

### 3.2. Model Consensus & Strict Tie Contract
Implemented in `compute_model_consensus()`:
- Evaluates the **latest recommendation per unique model package**.
- **Clear Majority**: Categorized as `KEEP`, `WATCH`, or `REMOVE` with percentage agreement (e.g. `KEEP (100%)`, `WATCH (67%)`).
- **Strict Tie Contract**: A 50/50 split (e.g. 1 KEEP vs 1 REMOVE) or 3-way tie is strictly classified as **`SPLIT (50%)`** with `is_consensus_tie = True`.
- **Single Model**: Tagged as `KEEP (100%) · Single Model`.

---

### 3.3. Validation Freshness / Staleness
Implemented in `compute_recency_staleness()`:
- **`Fresh`** ($\le 7\text{ days}$ elapsed): `🟢 Fresh (Xh / Xd ago)`
- **`Recent`** ($8\text{ to }30\text{ days}$ elapsed): `🟡 Recent (Xd ago)`
- **`Stale`** ($> 30\text{ days}$ elapsed): `🔴 Stale (Xd ago)`

---

### 3.4. Operational Priority Score & Advisory Rank
Implemented in `recommendation_store.py`:
- **`priority_rank` (Phase 1 Authoritative)**: Primary sorting order: `evidence_score DESC, keep_runs DESC, feature_name ASC`.
- **`operational_priority_score`**: $\text{round}(\text{evidence\_score} \times C, 2)$
- **`advisory_rank` (Phase 2A Preview)**: Sorted by `operational_priority_score DESC, keep_runs DESC, feature_name ASC`.
